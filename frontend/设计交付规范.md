## 二、组件规范（可复用 UI）⬜ 需从原型提炼成组件文档

原型里重复出现的 UI 应抽成**小程序自定义组件**（`miniprogram/components/`）。设计需给每类组件的：尺寸、状态（默认/按下/禁用）、间距、文案。

| 组件 | 用在哪些页 | 状态/变体 |
|------|-----------|-----------|
| 按钮（主/次/危险） | 全站 | 潮汐蓝实心 / 描边 / 灰+二次确认 |
| 内容卡片 | discover/player/event | 带海报 / 不带海报 |
| 呼吸圆环 | breathing/feedback | 缩放动效参数 |
| 打卡卡 | tide-checkin/card-gen | 深色渐变 + 节气/月相 |
| 底部弹窗 bottom-sheet | journal/event-detail | 上滑动效、遮罩 |
| 单按钮切换（日历↔时间线） | journal | 已做交互范例 |
| 月历网格 | event-calendar/journal | 有记录点 / 今日高亮 / 节气标注 |
| Tab 栏 | 全局 4 Tab | 需 **png 图标**（见第四节）|
| 空态 / 加载态 / 错误态 | 全站 | 加载用呼吸光点（非菊花）|

**交付物**：`组件规范.md`（每个组件一页：视觉稿 + 状态 + 间距标注），或直接在 Figma 里建 Component 并标注。

## 四、图标与图片资源 ⬜ 关键待补

原型里大量用 **unicode 字形**（◷ ⊝ ▷ ⟲ ◁ ◎ ⏱ ♡ ⇄ ⋯ ‹ ›）和**纯色块**占位，**这些不能直接上生产**。

| 资源 | 要求 | 用途 |
|------|------|------|
| Tab 图标 ×4（潮/海/岸/岛） | **81×81px png**，每个需「普通/选中」两态 | `app.json` tabBar（不支持字体图标/emoji）|
| 功能图标（播放/暂停/收藏/分享/定时/返回/更多…） | SVG 或 2x png，线框风格，潮汐蓝 | 各页按钮 |
| 呼吸/潮汐插画 | 矢量或高清位图 | breathing / tide-checkin |
| 活动海报、疗愈师头像、空间照片 | 真实素材 | event / healer / about |
| 品牌 logo（手写书法体） | 透明 png | 启动页 / 关于 |
| 字体文件（若用特定书法体） | 微信小程序不支持 ttf 直接引系统字，需 `wx.loadFont` 或转图片 | 品牌标题 |

**来源**：公司素材在 `/Users/charlotte/Desktop/成都共时海文化艺术发展有限公司/` 下（`LOGO二维码杂物/`、`空间照片/`、`图片素材/`、`活动:课程管理/` 等）。
**交付物**：`assets/` 目录（放在小程序工程内），并附 `assets-说明.md` 标注每个文件对应哪个元素。
