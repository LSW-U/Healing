# 共时海小程序 · 后端搭建步骤

> 配套设计文档：《00-设计理念》《01-页面架构》《03-交互逻辑》《04-扩展功能》。
> 本文档告诉你：后端怎么搭起来、怎么跑、接口有哪些、上线前要补什么。
>
> 技术栈：**Node.js (Koa) + SQLite + JWT**，零配置可本地直接跑，后期可平滑迁移到 MySQL/PostgreSQL。

---

## 一、环境准备

需要 **Node.js ≥ 18**（推荐 20 LTS）。

```bash
# 查看是否已安装
node -v
# 没装的话，去 https://nodejs.org 下载安装，或用 nvm：
# nvm install 20 && nvm use 20
```

SQLite 不需要单独安装——用的是 `better-sqlite3`，依赖装好即用（首次 `npm install` 会自动下载预编译二进制）。

## 三、配置环境变量

复制示例文件为 `.env`，按需填写：

```bash
cp .env.example .env
```

`.env` 关键项：

| 变量 | 说明 | 本地开发 |
|------|------|----------|
| `PORT` | 服务端口 | 默认 3000 |
| `JWT_SECRET` | JWT 签名密钥，**生产务必改成长随机串** | 可留默认 |
| `WX_APPID` | 微信小程序 AppID | **留空 = 开发模式** |
| `WX_SECRET` | 微信小程序 Secret | 留空即可 |
| `DB_PATH` | 数据库文件路径 | 留空（默认 `data/gongsihai.db`） |

> ⚠️ 未配置 `WX_APPID` 时自动进入「开发模式」：用任意 code（如 `"dev"`）就能登录，方便你先联调接口。配置真实 AppID/Secret 后即切换为真实微信登录。

## 四、初始化数据库 + 种子数据

## 七、小程序前端如何对接

在小程序里统一封装请求：

```js
const BASE = 'https://你的域名/api'   // 开发期可填 http://localhost:3000/api

function request(path, { method = 'GET', data, auth = true } = {}) {
  return new Promise((resolve, reject) => {
    const header = { 'Content-Type': 'application/json' }
    if (auth) header.Authorization = 'Bearer ' + wx.getStorageSync('token')
    wx.request({
      url: BASE + path,
      method,
      data,
      header,
      success: (res) => {
        const body = res.data
        if (body.code === 0) resolve(body.data)
        else if (body.code === 401) {
          // 登录过期，重新走登录流程
          reject(body.message)
        } else reject(body.message)
      },
      fail: reject,
    })
  })
}

// 登录示例（在小程序启动时或首次需要时调用）
async function login() {
  const { code } = await wx.login()
  const { token, user } = await request('/auth/login', { method: 'POST', data: { code }, auth: false })
  wx.setStorageSync('token', token)
}
```

> 注意：小程序正式请求必须用 **HTTPS 域名**，且要在微信公众平台「开发管理 → 服务器域名」里把你的 API 域名加进 request 合法域名。本地开发可在开发者工具勾选「不校验合法域名」。

## 八、微信登录原理

```
小程序 wx.login() → 拿到 code
        ↓
小程序 POST /api/auth/login { code }
        ↓
后端用 code 调微信 code2session（配置 WX_APPID/SECRET 时）
        ↓ 返回 openid / unionid
后端写入/读取 users，签发 JWT 返回前端
```

开发模式（未配 AppID）下，后端直接用 `dev_<code>` 当 openid，省去微信校验，方便你先把接口和前端跑通。

## 九、微信支付接入（上线前必做）

目前 `/api/events/:id/signup` 是**模拟支付**：直接把订单标为 `paid`，方便联调。

接真实微信支付（V3）需要：
1. 微信公众号/小程序平台申请**微信支付商户号**（企业资质）；
2. 配置 APIv3 密钥、证书；
3. 改造 `src/routes/events.js` 的报名逻辑为：
   - 调用「JSAPI 下单」接口拿 `prepay_id`；
   - 后端用商户私钥签名，把 `timeStamp/nonceStr/package/signType/paySign` 返回前端；
   - 前端 `wx.requestPayment(...)` 拉起支付；
   - 实现 `/api/pay/notify` 接收微信支付结果回调（验签后把 `signups.status` 改为 `paid` 并减库存）；
   - 处理退款（`refund` 接口 + 退款回调）。

> 建议单独封装 `src/services/payment.js` 管理下单/回调/退款，与路由解耦。

## 十、部署上线

### 方式 A：云服务器 + PM2（最常用）
```bash
npm install -g pm2
pm2 start src/app.js --name gongsihai
pm2 save && pm2 startup   # 开机自启
```
前面用 Nginx 反代 `localhost:3000` 并配置 HTTPS（Let's Encrypt 免费证书）。

### 方式 B：Docker
项目根可加 `Dockerfile`：
```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install --production
COPY . .
RUN npm run seed
EXPOSE 3000
CMD ["npm", "start"]
```
构建：`docker build -t gongsihai-backend . && docker run -d -p 3000:3000 gongsihai-backend`

> SQLite 文件在容器内，若用容器/多实例部署，建议把 `data/` 挂到数据卷，或迁移到外部 MySQL（见下）。

## 十一、从 SQLite 迁移到 MySQL（用户量大时）

代码已把数据库访问收敛在 `src/db/` 与各路由的 `db.prepare(...)`。迁移思路：
1. 引入 `mysql2`，在 `src/db/index.js` 根据 `DB_TYPE` 切换连接；
2. 把 `schema.sql` 改写成 MySQL 建表语句（类型、自增、JSON 列）；
3. 把 `.prepare().get/all/run` 改为 `mysql2/promise` 的 `query` 写法（参数用 `?` 占位，语法基本兼容）；
4. 字符串 JSON 字段在 MySQL 8 可直接用 `JSON` 类型并在接口层继续 `JSON.parse`。

---

## 十二、安全与合规（心理类重点）

- **隐私数据**：疗愈日记、感受记录属敏感心理数据，建议在存储层做加密（如 `aes-256-gcm`，密钥放环境变量），并在「设置」提供**导出 / 删除**入口（对应 `DELETE` 用户及关联数据）。
- **JWT 密钥**：生产环境必须改成随机长串，且不要提交进 git。
- **HTTPS**：所有接口走 HTTPS，避免 openid / 手机号明文传输。
- **内容审核**：共修圈公开发言（远期「感受匿名精选」）需审核流程，防止负向内容。
- **危机援助**：`/api/crisis` 已内置，前端在日记/感受检测到高危词时主动弹出，务必保留且不可移除。
