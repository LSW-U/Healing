# 共时海 · 页面原型实现任务安排

> 本文档统筹所有页面原型的实现：每页一个独立 HTML 文件，便于逐页评审与开发对接。

## 一、统一设计规范（提炼）

### 1.1 色板
| 角色 | 色名 | 色值 |
|------|------|------|
| 主背景 | 月白 | `#F5F3EF` |
| 次背景 | 晨雾 | `#EAE6DF` |
| 雾深 | — | `#DDD8CF` |
| 主色 | 潮汐蓝（品牌色） | `#5B7B8A` |
| 主色深 | — | `#4A6B7A` |
| 辅色 | 浅木 | `#C9B59A` |
| 强调 | 墨绿 | `#3F5E5A` |
| 文字主 | 墨 | `#2B2B2B` |
| 文字次 | 烟灰 | `#8A8A8A` |
| 警示 | 暮霞 | `#B8746A` |

### 1.2 字体
- 标题：思源宋体 / 苹方-粗体（衬线感，文化气息）
- 正文：苹方-常规
- logo 区：使用品牌手写书法体 logo 图（实际开发以图片为准，见 `LOGO二维码杂物/共时海logo水印/`）

### 1.3 圆角与间距
- 卡片圆角：16-18px
- 按钮圆角：胶囊形（全圆角）
- 页面左右边距：24px（对应 48rpx）

### 1.4 手机框
- 宽 375px（iPhone 标准），居中展示
- 顶部状态栏 + 导航栏，底部 Tab 栏（4 Tab）

### 1.5 交互约定（见《03》）
- 点击反馈：缩放 0.98 + 涟漪
- 跳转：淡入淡出 300-400ms
- 主操作按钮：潮汐蓝实心 + 白字
- 次操作：描边 / 文字
- 加载态：呼吸光点（不用菊花）
- 空状态：留白 + 一句温柔文案

### 1.6 公共组件
底部 Tab 栏、状态栏、导航栏（返回+标题+操作）、卡片、按钮（主/次/文字）、标签、进度条、呼吸圆环

## 三、逐页实现要点

### P01 启动问候页 `p01-greet.html`
- **目标**：每日第一眼，建立安心仪式感
- **核心元素**：节气日期+物候、每日一语（诗句）、柔和背景图、"进入共时海"按钮
- **关键交互**：停留 2-3s 按钮高亮；点击 → P02 发现页
- **依赖**：节气数据、每日一语库、背景图
- **无底部 Tab**

### P02 潮·发现页 `p02-discover.html`
- **目标**：发现今日疗愈内容
- **核心元素**：nav（搜索/菜单）、早安问候、今日共时推荐卡（大）、主题专栏列表、内容列表项
- **关键交互**：搜索 → P20；推荐卡播放 → P05；专栏更多 → 专栏列表；列表项 → P12；Tab 切换
- **Tab active = 潮**

### P03 海·练习页 `p03-practice.html`
- **目标**：四大练习入口
- **核心元素**：四大入口卡（呼吸/冥想/声音/助眠）、呼吸圆环演示
- **关键交互**：呼吸 → P04；冥想/声音 → 内容列表；助眠 → 助眠模式；圆环演示 → P04
- **Tab active = 海**

### P04 呼吸练习进行中 `p04-breathing.html`
- **目标**：全屏沉浸呼吸引导
- **核心元素**：呼吸圆环动画（8s 循环）、"吸气"文字、计数、"轻触结束"
- **关键交互**：结束 → P13 练习完成反馈页；圆环被动展示
- **无 Tab**（沉浸）

### P05 音频播放器 `p05-player.html`
- **目标**：音频播放控制
- **核心元素**：封面、标题副标题、进度条+时长、控制按钮（上一段/后退/播放暂停/下一段/分段）、定时/收藏/分段
- **关键交互**：进度拖动；各控制；定时弹层；收藏切换
- **无 Tab**（沉浸播放）

### P06 岛·我的页 `p06-me.html`
- **目标**：个人中心
- **核心元素**：头像昵称签名、统计（时长/天数/次数）、入口列表（疗愈日记/收藏/提醒/订单）
- **关键交互**：头像 → P27；各入口 → 子页
- **Tab active = 岛**

### P07 活动日历页 `p07-calendar.html`
- **目标**：月历视图看活动
- **核心元素**：月份切换、月历网格（节气标注/活动圆点/今日高亮）、选中日展开活动卡、往期回顾入口
- **关键交互**：列表切换 → P11 瀑布流；月份切换；日期点击展开；报名 → P14
- **Tab active = 岸**

### P08 潮汐打卡页 `p08-tide-checkin.html`
- **目标**：打卡回看（打卡行为在 P13 触发）
- **核心元素**：状态（连绵 X 日·满潮）、潮汐图、打卡卡（节气/月相/一句话/分享）、感受时间线"最近的涟漪"
- **关键交互**：共修圈 → P09；分享 → 分享面板；时间线全部 → 全部记录；条目展开
- **Tab active = 岛**

### P09 共修圈页 `p09-circle.html`
- **目标**：群打卡陪伴
- **核心元素**：圈头（共同潮汐·第 X 日+周期进度）、共同潮汐墙（头像列）、同修打卡流（心情+一句话+互相温暖）、发打卡按钮
- **关键交互**：设置 → 圈设置；也在/陪你 → 发送回应；发打卡 → P32 编辑器
- **Tab active = 岸**

### P10 岸·连接 Tab 落地页 `p10-shore.html`
- **目标**：聚合岸下入口
- **核心元素**：引导语、共修圈状态卡、入口列表（疗愈师/课程/线下活动[近期 badge]/关于）
- **关键交互**：各入口 → 列表页
- **Tab active = 岸**

### P11 活动瀑布流 `p11-stream.html`
- **目标**：瀑布流看活动
- **核心元素**：分类标签横滑、两列瀑布流（带海报/不带海报两种卡）、报名/候补按钮
- **关键交互**：日历切换 → P07；分类筛选；卡片 → P19；报名 → P14
- **Tab active = 岸**

### P12 内容详情页 `p12-content-detail.html`（MVP 必补）
- **目标**：单条冥想/声音内容详情
- **核心元素**：封面+标题+副标题、疗愈师署名、时长/形式/场景标签、简介、大播放按钮、收藏/定时/分享、相关推荐
- **关键交互**：播放 → P05；收藏切换；相关推荐 → P12
- **依赖**：内容数据（冥想音频）

### P13 练习完成反馈页 `p13-feedback.html`（MVP 必补）
- **目标**：完成练习后打卡+感受记录触发点
- **核心元素**：温柔反馈语、心情选择（5 个柔和词）、一句话记录（可选）、关联练习、回到发现/再练一次
- **关键交互**：心情选择 → 标签；记录 → 生成打卡卡 → P08；情绪标签反哺推荐
- **重要**：打卡行为在此触发，不在 P08

### P14 报名成功页 `p14-signup-success.html`（MVP 必补）
- **目标**：活动报名成功闭环
- **核心元素**：成功反馈（温柔，非"成功!"）、活动信息卡（时间/地点/名额）、加入日历提醒、导航按钮、查看我的报名
- **关键交互**：加日历 → 订阅消息；导航 → 微信地图；查看 → P24

### P15 疗愈师列表 `p15-healer-list.html`
- **核心元素**：筛选（流派/形式）、疗愈师卡片（头像/名字/资质/一句话/标签）
- **依赖**：`人物介绍.pptx`、`个人简介.pptx`

### P16 疗愈师详情页 `p16-healer-detail.html`
- **核心元素**：头像+介绍（经历/受训/擅长）、服务列表、用户反馈、预约入口、**非医疗边界声明**

### P17 课程列表 `p17-course-list.html`
- **核心元素**：筛选（形式/时间/价格/流派）、课程卡片
- **依赖**：`共时海冥想课程体系.docx` 等

### P18 课程详情与报名 `p18-course-detail.html`
- **核心元素**：课程介绍、导师、课时、适合人群、价格、报名须知、报名 → 支付

### P19 活动详情页 `p19-event-detail.html`
- **核心元素**：封面、活动名+引导语、时间/地点（导航）/名额/费用、介绍、适合人群、报名须知、报名 → P14
- **依赖**：活动方案库、`空间照片/`

### P20 搜索页 `p20-search.html`
- **核心元素**：搜索框、热搜+历史、结果按类型分组（内容/疗愈师/课程/专栏）

### P21 疗愈日记 `p21-journal.html`
- **核心元素**：日历视图+时间线视图切换、记录卡（日期/天气节气/心情/文字/配图）、满月新月标记、**危机援助触发**
- **隐私优先**、高危词检测

### P22 我的收藏 `p22-favorites.html`
- **核心元素**：分类（内容/疗愈师/课程）、分组管理

### P23 定时提醒设置 `p23-reminder.html`
- **核心元素**：晨起/午间/睡前开关、勿扰时段、推送文案预览

### P24 订单与报名 `p24-orders.html`
- **核心元素**：报名记录、支付记录、退款状态

### P25 设置 `p25-settings.html`
- **核心元素**：账号、通知、隐私（导出/删除）、播放偏好、关于、退出

### P26 关于共时海 `p26-about.html`
- **核心元素**：品牌故事、团队、联系方式、合作、隐私政策、用户协议、公众号/小红书二维码
- **依赖**：`共时海·疗愈共创空间（05版）.pptx`、`共时海介绍(1).pdf`、logo

### P27 个人资料 `p27-profile.html`
- **核心元素**：头像、昵称、签名、手机绑定

### P28 消息中心 `p28-messages.html`
- **核心元素**：订阅消息、报名通知、共修圈提醒、系统消息

### P29 往期回顾 `p29-archive.html`
- **核心元素**：往期活动图文集（"潮汐档案"）

### P30 共修圈创建 `p30-circle-create.html`

## 六、技术说明

- 每个 html 独立可用，浏览器直接打开
- 初期公共样式内联各页（便于独立评审），稳定后可提取 `common.css`
- 手机框居中展示，模拟 375px 宽
- 图标用占位符号或简单 SVG，真实开发替换图标库
- 交互用最小 JS 实现点击跳转/状态切换
- 品牌主色统一用 `#5B7B8A`（潮汐蓝），通过 CSS 变量 `--tidal` 管理

## 七、协作建议

- **设计师**：基于此安排逐页做高保真设计稿
- **开发**：按优先级对接，每页完成后在上方表格"状态"列打勾
- **内容运营**：同步整理素材（冥想音频/课程/疗愈师简介/活动方案）按页面结构上架
- **评审**：每页独立 html 便于逐页过审，避免长页面滚动疲劳
