# 共时海小程序 · 页面 ↔ 接口映射

> 开发按此表接后端。接口前缀 `/api`，返回统一 `{code,data,message}`。
> 需登录接口请求头带 `Authorization: Bearer <token>`。
> 字段名来自 `../后端/src/db/schema.sql`（JSON 字段在接口层已是对象/数组）。

图例：✅ 已有接口 ｜ ⚠️ 接口可用但需注意 ｜ 🚧 后端暂缺/需补充

## 一、启动与发现（潮）

### P01 启动问候页 `pages/greet`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/daily-greeting` ✅ |
| 返回 | `{ solarTerm, solarTermDate, quote, source }` |
| 渲染 | 节气名（如「立秋」）+ 每日一语 + 来源；点「进入共时海」→ `wx.switchTab` 到 discover |
| 备注 | 后端已内置 2026 二十四节气 + 每日一语种子 |

### P02 发现页 `pages/discover`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/contents/recommend/today`（今日共时）✅ ＋ `GET /api/columns`（专栏）✅ ＋ `GET /api/contents?sort=hot`（内容流）✅ |
| 返回-推荐 | `{ content:{id,title,cover,type,duration}, reason }` |
| 返回-专栏 | `[{id,title,cover,intro}]` |
| 返回-内容 | `[{id,title,subtitle,cover,type,duration,play_count}]` |
| 交互 | 推荐卡/内容卡 → `navigateTo` content-detail；专栏 → column 详情（用 contents?columnId 或后端 columns/:id） |
| 备注 | 顶部「今日打卡」快捷入口（设计稿有）→ 跳 tide-checkin |

### P20 搜索页 `pages/search`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/search?q=关键词` ✅ |
| 返回 | `{ contents:[...], healers:[...], columns:[...] }` |
| 备注 | 全局入口，从 discover 顶栏搜索图标进入 |

## 二、练习与音频（海）

### P03 练习页 `pages/practice`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/contents?type=breathing&type=meditation&type=sound&type=sleep`（或分类分别拉）✅ ＋ `GET /api/breathing-patterns` ✅ |
| 返回-内容 | `[{id,title,cover,type,duration}]` |
| 返回-呼吸法 | `[{id,name,inhale,hold_in,exhale,hold_out,cycles,description}]` |
| 交互 | 呼吸入口 → breathing（带 patternId）；内容卡 → player |

### P04 呼吸练习中 `pages/breathing`
| 项 | 内容 |
|----|------|
| 接口 | 进入时取 `GET /api/breathing-patterns/:id` ✅（或从列表带参） |
| 渲染 | 圆环按 inhale/hold_in/exhale/hold_out 节奏缩放；文案「吸气/屏息/呼气」 |
| 完成 | 退出时 `POST /api/checkins`（见 P13）触发打卡 |

### P05 播放器 `pages/player`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/contents/:id` ✅ |
| 返回 | `{id,title,subtitle,cover,healer_id,type,duration,audio_url,description,sections,is_free,play_count}` |
| 播放 | `wx.getBackgroundAudioManager()` 用 `audio_url`；`sections` 是 `[{name,start}]` 用于分段跳转 |
| 交互 | 收藏→`favorites`；定时→本地定时器；分享→`wx.showShareMenu` |

### P12 内容详情页 `pages/content-detail`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/contents/:id` ✅（同 P05，详情更全）＋ 疗愈师 `GET /api/healers/:id`（若 healer_id 有值）✅ |
| 渲染 | 封面/标题/标签(scene_tags,form_tags)/简介/相关推荐/底部「开始播放」 |
| 交互 | 开始播放 → player；收藏/分享/定时 |

### P13 练习完成反馈页 `pages/feedback`
| 项 | 内容 |
|----|------|
| 接口 | `POST /api/checkins` ✅（body: `{content_id,mood,note}`）＋ 可选 `POST /api/feelings`（body: `{mood,text,related_content_id}`）|
| 返回-打卡 | `{id,date,streak,tide_level}` |
| 备注 | **打卡行为在此页触发**（schema 注释明确：打卡在「练习完成反馈页」） |

## 三、连接（岸）

### P10 岸·连接落地页 `pages/shore`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/circles`（我的圈/推荐）✅ ＋ `GET /api/healers` ✅ ＋ `GET /api/events?month=` ✅ ＋ `GET /api/columns` ✅ |
| 渲染 | 共修圈状态卡（取我加入的圈 current_day/cycle_days）+ 疗愈师/课程/活动/关于 入口 |
| 交互 | 各入口 → 对应列表/详情页 |

### P15 疗愈师列表 `pages/healer-list`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/healers?flow=颂钵&form=1v1`（flow=流派, form=形式）✅ |
| 返回 | `[{id,name,avatar,title,intro,tags,is_contracted}]` |
| 交互 | 卡 → healer-detail |

### P16 疗愈师详情 `pages/healer-detail`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/healers/:id` ✅ |
| 返回 | `{id,name,avatar,title,bio,tags,services,is_contracted}` |
| 备注 | `services` 是 `[{name,form,price}]` 数组；「预约」当前无独立预约接口，建议走消息/客服或复用 events 报名机制 🚧（需与后端确认） |

### P17 课程列表 `pages/course-list`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/contents?type=course`（course 为内容类型之一）✅ |
| 返回 | 同 contents 列表 |
| 备注 | **后端无独立 course 实体**；课程即 `contents` 中 `type='course'` 的条目。若课程有「价格/报名」，复用 events 报名或 🚧 待后端加 course 表 |

### P18 课程详情 `pages/course-detail`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/contents/:id` ✅ |
| 渲染 | 封面/价格（contents 仅有 is_free，无 fee 字段 ⚠️）/大纲(sections)/适合人群(form_tags)/须知 |
| 备注 | **价格字段缺失**：付费课程的价格建议放到 events 或 🚧 后端 contents 补 `fee` 字段 |

### P07 活动日历页 `pages/event-calendar`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/events?month=2026-09` ✅ |
| 返回 | `[{id,title,cover,start_time,end_time,location,remaining_slots,total_slots,fee,is_solar_term,solar_term,status}]` |
| 渲染 | 月历网格；有活动日标圆点；节气日标浅木；今日高亮；点日期展开当日活动 |
| 交互 | 活动 → event-detail |

### P11 活动瀑布流 `pages/event-stream`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/events`（可带 `type`/`month`）✅ |
| 渲染 | 两列交错；带 cover 用海报、无 cover 用色块；名额进度条 |
| 交互 | 卡 → event-detail；顶部分类筛选用 `?type=` |

### P19 活动详情页 `pages/event-detail`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/events/:id` ✅ ＋ 报名 `POST /api/events/:id/signup` ✅（**当前模拟支付**）|
| 返回-详情 | 全字段（见 schema events）+ `remaining_slots` |
| 返回-报名 | `{signup_id,status:'paid'}`（模拟）|
| 交互 | 报名 → signup-success；导航用 `wx.openLocation`（latitude/longitude）|

### P14 报名成功页 `pages/signup-success`
| 项 | 内容 |
|----|------|
| 接口 | `GET /api/signups`（取最新一条）✅ |
| 返回 | `{id,event_id,event_title,status,paid_at,name,phone}` |
| 交互 | 加入日历提醒（本地 `wx.addPhoneCalendar` 或订阅消息）；查看报名 → orders |
