# 共时海 · 疗愈小程序页面架构与功能规划

> 本文档承接《00-设计理念与方向》，将设计理念落地为具体的页面结构、功能模块与用户旅程，作为原型设计与开发的依据。

---

## 一、整体信息架构

### 1.1 底部 Tab 结构

采用 4 Tab 结构，命名延续海洋意象：

| Tab | 名称 | 图标意象 | 一句话定位 |
|-----|------|----------|-----------|
| 1 | 潮 | 潮汐线条 | 发现今日的疗愈 |
| 2 | 海 | 海面/波纹 | 进入练习与播放 |
| 3 | 岸 | 海岸线/灯塔 | 连接疗愈师与课程 |
| 4 | 岛 | 岛屿轮廓 | 我的记录与成长 |

> 备选命名（更直白）：发现 / 练习 / 课程 / 我的。建议保留意象命名，并配合清晰图标降低认知成本。

## 二、Tab 一：潮（发现）

### 2.1 启动问候页（每日一语）

- **定位**：每次打开小程序的第一眼，建立"安心"仪式感
- **内容**：
  - 当日日期 + 节气/物候（如"立秋 · 凉风至"）
  - 一句精选短句（诗句/禅语/原创引导语）
  - 一张柔和背景图（按节气/天气变化）
  - "进入共时海"按钮（轻提示，非强制等待）
- **细节**：停留 2-3 秒后按钮高亮，不强推广告位

### 2.2 今日共时推荐

- **定位**：基于"共时性"理念的推荐，让内容与用户此刻共振
- **推荐维度**：
  - **时间共时**：节气、时辰、早晚（晨起/午间/睡前不同内容）
  - **情绪共时**：用户近期日记情绪标签（需授权）
  - **天气共时**：调用天气API，雨天推雨声内容等（可选）
- **呈现**：1 张大图卡片 + 2-3 张次级卡片，不强瀑布流

### 2.3 主题专栏

- **定位**：策展式内容组织，体现"艺术性"，区别于纯算法流
- **示例专栏**：
  - 「二十四节气疗愈」——每个节气一套内容
  - 「深夜电台」——睡前陪伴
  - 「城市潮汐」——通勤碎片放松
  - 「东方器物」——颂钵/古琴/手碟
- **呈现**：专栏封面 + 简介 + 内容列表

### 2.4 全部内容（分类筛选）

- **分类维度**（可多选筛选）：
  - 按形式：冥想引导 / 呼吸练习 / 声音疗愈 / 音乐 / 自然声
  - 按目的：放松 / 助眠 / 专注 / 情绪调节 / 自我探索
  - 按时长：5分钟内 / 5-15分钟 / 15分钟以上
- **排序**：推荐 / 最新 / 热门（默认推荐）

### 2.5 内容详情页

- **要素**：
  - 封面图 + 标题 + 副标题（一句引导语）
  - 疗愈师/创作者署名
  - 时长、形式标签、适合场景
  - 简介（2-3段，留白排版）
  - 主操作：开始播放（大按钮）
  - 次操作：收藏、加入定时、分享
  - 相关推荐（同主题/同目的）
- **注意**：避免评论区过载，可设"静默收藏"替代评论

## 三、Tab 二：海（练习）

### 3.1 练习主页

四大练习入口卡片，纵向排列：

| 入口 | 图标 | 说明 |
|------|------|------|
| 呼吸练习 | 呼吸圆环 | 引导式呼吸（4-7-8、盒式呼吸等） |
| 冥想引导 | 月亮/水面 | 人声引导冥想，按时长分类 |
| 声音疗愈 | 颂钵/波纹 | 颂钵、自然声、环境音 |
| 助眠模式 | 星月 | 睡前专属，含定时关闭 |

每卡片显示：图标 + 名称 + 一句引导 + 上次练习时间（若有）

### 3.2 呼吸练习工具页（重点创新）

- **定位**：独立工具型页面，视觉化呼吸节奏
- **核心交互**：
  - 圆形（或水滴形）图形随呼吸节奏缩放
  - 文字同步提示："吸气… / 屏息… / 呼气… / 屏息…"
  - 可选呼吸法：4-7-8助眠、盒式4-4-4-4、共振6-6、自定义
  - 可设循环次数
  - 背景音可选（轻柔环境声）
- **动效要求**：圆环缩放必须丝滑，配合真实呼吸时长，这是该页成败关键
- **完成后**：轻反馈（如"完成 5 轮呼吸"）+ 引导记录此刻感受

### 3.3 音频播放器页

- **布局**：
  - 上：封面图 + 内容标题
  - 中：进度条（细线，不抢戏）+ 时长
  - 下：播放/暂停大按钮 + 上一段/下一段 + 定时 + 收藏
- **特色功能**：
  - **分段跳转**：长内容可分段（如冥想分"准备-引导-收束"）
  - **背景音叠加**：可选环境声作为底层（如冥想+雨声）
  - **定时关闭**：15/30/60/90分钟 + 自定义 + "播完即停"
  - **睡眠模式**：屏幕变暗、按钮简化

### 3.4 练习完成反馈页

- **目的**：建立"完成-记录"的习惯闭环
- **内容**：
  - 一句温柔反馈（非"太棒了！"式煽情）
  - 此刻心情选择（5个柔和表情/词，非emoji）
  - 一句话记录（可选输入）
  - "回到发现" / "再练一次"
- **注意**：此页接入情绪标签，反哺"今日共时推荐"

## 四、Tab 三：岸（连接）

### 4.1 疗愈师列表

- **卡片信息**：头像 + 名字 + 资质/流派 + 一句话介绍 + 标签（如"颂钵""正念""表达性艺术"）
- **筛选**：按流派、按可预约形式（线上/线下）
- **注意**：资质需真实可核验，避免过度包装

### 4.2 疗愈师详情页

- **内容**：
  - 头像 + 介绍（个人经历、受训背景、擅长方向）
  - 提供服务列表（1v1咨询、团体工作坊、音频课程）
  - 用户反馈（精选，非打分排名）
  - 预约/咨询入口
- **伦理**：明确"非医疗心理咨询"边界

### 4.3 课程/工作坊列表

- **类型**：
  - 录播课程（自主学）
  - 直播课程（固定时间）
  - 线下工作坊（需到场）
- **筛选**：形式、时间、价格区间、流派

### 4.4 课程详情与报名

- **要素**：课程介绍、导师、课时安排、适合人群、价格、报名须知
- **报名流程**：确认信息 → 支付（微信支付） → 报名成功 → 加入日历提醒
- **合规**：价格透明、退改规则明确

### 4.5 线下活动 · 活动日历页

#### 4.5.1 定位与原则
- **定位**：发挥工作室线下优势，打造"共时海"实体场域。以**时间维度**为主轴组织线下活动，呼应"共时性"理念——活动自然落在节气、特定日子上。
- **轻量原则**：**不新增独立 Tab**，作为「岸·连接」下的二级入口；不破坏 4 Tab 架构平衡；活动少时页面不显空（日历本身就是"静中有动"的形态）。
- **示例活动**：节气茶会、颂钵音疗沙龙、正念徒步、艺术疗愈工作坊、新月/满月冥想圈

#### 4.5.2 触达策略：多点曝光 + 单点落地
线下活动有"报名截止、名额、地点"等硬约束，需既被看到、又能完整走完报名。采用：

| 层级 | 位置 | 作用 |
|------|------|------|
| ① 曝光 | 启动页·轻提示（仅近期有活动时） | 仪式感提醒，不打扰日常 |
| ① 曝光 | **发现页·顶部横幅**（主引流位） | 日常打开率最高，固定卡位引流 |
| ① 曝光 | 节气共时推荐·关联 | 活动与节气内容联动，符合共时性 |
| ② 落地 | **岸·连接 → 线下活动（活动日历页）** | 完整报名流程在此完成 |
| ③ 沉淀 | 岛·我的 → 报名记录 | 报名成功后自动归入 |

曝光层均为"引流入口"，点击统一跳转到活动日历页；落地层为唯一完整功能页。

#### 4.5.3 活动日历页结构

**顶部栏**
- 月份切换（‹ 立秋月 ›）+ 视图切换（月历 / 列表）
- 当月活动数提示（如"本月 6 场相聚"）

**月历视图（默认）**
- 标准月历网格，柔和配色
- **有活动的日期**：日期下方一个小圆点（潮汐蓝），多场活动则多个点
- **节气日期**：用浅木色标注节气名（如"立秋""处暑"），活动若与节气关联则该日高亮
- **今日**：潮汐蓝圆点底
- 点击某日 → 下方展开当日活动卡片（不跳页，原地展开）
- 无活动的日期保持留白，不强填内容

**列表视图（切换）**
- 按时间正序排列"即将开始"的活动
- 每条卡片：日期 + 活动名 + 地点 + 剩余名额 + 状态标签（报名中/即将满/已满/已结束）
- 已结束活动灰阶处理，可点击看回顾

**底部"往期回顾"入口**
- 进入往期活动图文集（沉淀工作室过往场域记忆）

#### 4.5.4 活动详情页
点击日历中的活动卡片进入：

- **主信息**：活动名 + 一句引导语 + 封面图（柔和、留白构图）
- **关键信息卡**：
  - 时间（含星期、时长）
  - 地点（带"导航"按钮，调用微信地图）
  - 名额（剩余 X / 总 Y）
  - 费用（明码标价，或"免费·公益"）
- **介绍**：2-3段，活动内容、流程、你将体验什么
- **适合人群**：标签式（如"无需基础""适合压力人群"）
- **报名须知**：退改规则、迟到/缺席说明、着装建议（如"宽松衣物"）
- **主操作**：立即报名 → 微信支付 → 报名成功页
- **报名成功页**：加入日历提醒（订阅消息）+ 地点导航 + "查看我的报名"

#### 4.5.5 共时海特色细节
- **节气联动**：日历标注二十四节气，节气活动高亮，强化"共时"品牌
- **名额意象**：剩余名额可用潮汐意象表达（满额=满潮、还有位=涨潮中），文案如"潮将满，余 2 席"
- **新月/满月标记**：月相标记在日历上，适合做月相主题冥想活动
- **往期回顾**：每场活动沉淀一段图文/影像，成为工作室的"潮汐档案"

#### 4.5.6 报名与支付流程
确认信息（姓名/手机）→ 微信支付（需企业资质+微信支付商户号）→ 报名成功 → 推送订阅消息（活动前1天提醒、当天导航）→ 现场签到（可选扫码签到）

#### 4.5.7 一期/二期建议
- **一期（MVP）可缓**：若线下活动尚未常态化，可先在发现页做活动卡片直接展示+留言报名，不做日历
- **二期做**：活动日历页 + 报名支付 + 订阅提醒
- **三期**：往期回顾沉淀、活动复购、会员优先报名

### 4.6 共修圈（群打卡陪伴）

> 归属说明：共修圈入口在「岸·连接」Tab 下（连接同修）；个人打卡与感受记录在「岛·我的」下（见 5.4）。岸=连接他人与场域（疗愈师/活动/共修圈），岛=个人空间（记录/成长），语义不重叠。

- **定位**：有周期的共修陪伴，不是闲聊群。连接同修，共同潮汐
- **建圈**：用户可创建或加入共修圈，设定周期（21天 / 49天）
- **圈内规则**：只能发"打卡 + 感受"，不能发任意内容——降低审核成本，避免压力群
- **共同潮汐墙**：显示今天谁打了卡（柔和头像列），**不显示打卡天数排名**，只表达"一起在"，不比较
- **互相温暖**：可对他人打卡/感受轻回应（预设温柔词，如"也在""陪你"），不开放自由评论（防负向）
- **周期纪念**：周期结束生成"共修潮汐"纪念，可延续下一期

## 五、Tab 四：岛（我的）

### 5.1 个人中心主页

- **顶部**：昵称 + 一句个人签名（用户自定义）+ 累计练习时长/天数
- **卡片入口**：疗愈日记、我的收藏、打卡成长、定时提醒、订单、设置
- **今日状态**：是否已练习、推荐今日内容

### 5.2 疗愈日记（核心情感功能）

- **定位**：用户的私密情绪与练习记录本
- **记录维度**：
  - 日期 + 天气/节气
  - 心情标签（柔和词，如"平静/起伏/沉静/微光"）
  - 一段文字（可选）
  - 关联今日练习内容
  - 配图（可选，限1张，柔化处理）
- **呈现**：按月日历视图 + 时间线视图切换
- **隐私**：默认本地优先存储，云端加密同步（用户可选），明确告知
- **特色**：满月/新月/节气时，日历有特别标记，引导回顾
- **伦理**：检测到高危情绪词（如自伤、绝望）时，温和弹窗 + 援助热线入口

### 5.3 我的收藏

- 分类：内容收藏、疗愈师关注、课程收藏
- 支持分组（如"睡前""通勤"）

### 5.4 打卡与感受记录（个人维度）

打卡与感受记录是共时海的"留存引擎"。核心原则：**不把断卡当失败**——潮汐有涨有落是自然的，断了只是潮退，海还在。

#### 潮汐打卡（新形式，不用日历）
- **触发**：每次完成冥想/呼吸/声音练习后，在"练习完成反馈页"轻引导打卡
- **可视化形式**：潮汐图（非日历）
  - 连续打卡 → 潮位累积上涨；连续 7 天 = 满潮
  - 断卡 → 潮退一格，但**不归零**，只是潮位缓缓下降
  - 不用日历的理由：已有活动日历页 + 疗愈日记日历两个日历，打卡再日历会重复；且日历的"空白格=断卡"有失败感，潮汐图更品牌、更温柔
- **打卡卡**：每次打卡自动生成一张美感卡（当日节气/月相 + 你的一句话 + 练习名），可收藏、可分享到共修圈
- **不做**：积分商城、炫耀式排行榜、断卡惩罚

#### 感受记录与回看
- **记录要轻**：心情标签点选 + 一句话（可选）+ 自动关联刚做的练习 + 配图（可选1张，柔化）
- **语音记录**：按住说一句，比打字更情绪化，适合不愿打字的人
- **回看形式**：
  - 时间线流（默认）：最新在上，每条卡片点开看全文
  - 情绪轨迹曲线（月度）：基于心情标签的趋势，柔化呈现，呼应潮汐
  - 满月/新月回顾：月相时引导回顾这段时间的感受（仪式感）
- **隐私**：感受默认私密，本地优先 + 云端加密同步（用户可选）；分享是主动行为，且可仅分享"心情 + 一句话"不分享全文
- **危机衔接**：检测高危词（自伤、绝望等）→ 温和弹窗 + 援助热线入口

#### 共修圈（入口在岸·连接，见 4.6）

> 共修圈是社交维度，归属「岸·连接」（连接同修），与个人打卡/感受记录（岛·我的）分离。详细玩法见 4.6。

#### 成长可视化（汇总）
- 累计练习时长（小时）
- 潮汐打卡图（连续性）
- 情绪轨迹曲线（状态趋势）
- 年度潮汐图（年底生成，类似年度报告）
- 已完成课程数
- **避免**：不做积分商城、不做炫耀式排行榜

### 5.5 定时提醒设置

- **场景**：晨起练习、午间放松、睡前助眠
- **形式**：温和推送文案（如"潮汐将至，留5分钟给自己"）
- **尊重**：可一键关闭全部、可设勿扰时段

### 5.6 订单与报名

- 课程报名记录、支付记录、退款状态

### 5.7 设置

- 账号、通知、隐私（数据导出/删除）、播放偏好（默认音量/背景音）、关于、退出

## 七、核心用户旅程

### 7.1 新用户首次体验

```
打开 → 启动问候页 → 引导选择此刻需求
（放松/助眠/专注/探索）→ 推荐匹配内容 → 体验1次短练习
→ 完成反馈 → 轻引导收藏/打卡 → 进入主页
```

关键：**3分钟内让用户完成一次完整的疗愈体验**，建立"有用"的第一印象。

### 7.2 日常使用（留存型）

```
推送提醒 → 打开 → 今日共时推荐 → 练习 → 记录日记 → 关闭
```

每次用时 5-10 分钟，培养每日陪伴习惯。

### 7.3 深度用户（付费转化）

```
持续免费内容使用 → 参与主题专栏 → 关注某疗愈师
→ 报名课程/工作坊 → 线下体验 → 持续复购
```

### 7.4 情绪低谷时刻

```
打开日记 → 记录情绪 → 系统识别低落 → 推送温和内容
（如适用）触发援助入口 → 用户自主选择
```

全程**不评判、不施压**，只提供"在这里"的陪伴感。

## 九、技术与平台注意点

- **框架**：建议 Taro 或原生微信小程序（若未来需多端可考虑 Taro/uni-app）
- **音频**：使用微信 `BackgroundAudioManager` 实现后台播放
- **支付**：微信支付（V2/V3 接口），需企业资质
- **订阅消息**：用于定时提醒，需用户授权
- **数据存储**：云开发（免运维）或自建后端
- **隐私合规**：心理类数据建议加密存储，提供导出与删除功能
- **性能**：图片懒加载、音频预加载、首页首屏控制在 1.5s 内
