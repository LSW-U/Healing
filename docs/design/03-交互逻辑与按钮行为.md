# 共时海 · 交互逻辑与按钮行为

> 本文档定义 33 个页面原型（`prototypes/html/p01~p33`）中各页面按钮/元素的交互逻辑、跳转关系与状态反馈，是**开发与设计的对齐依据**。配套《00-设计理念与方向》《01-页面架构与功能规划》《04-扩展功能与元素实现规划》。
>
> 阅读约定：原型中部分图标用占位符号（○ ⊝ ▷ ⟲ ◁ ◎ ⏱ ♡ ⇄ ⋯ ‹ ›），下表标注其真实含义。
> 表内「状态/备注」标注原型当前接线情况：`[已实现]` = HTML 已接 JS/href；`[待实现]` = 规范已定义但原型尚未接跳转，开发按此实现。

## 一、交互通用约定

| 类别 | 规则 |
|------|------|
| 点击反馈 | 轻微缩放 0.98 + 涟漪扩散；时长 150ms |
| 跳转动效 | 淡入淡出 300-400ms，**不用左滑**（保持"慢"的调性） |
| 主操作按钮 | 潮汐蓝实心 + 白字（如"立即报名""开始播放""创建共修圈"） |
| 次操作按钮 | 描边潮汐蓝 / 纯文字链接（如"收藏""更多›"） |
| 危险/退出 | 灰色或文字按钮，二次确认（如"退出登录""删除我的数据"） |
| 加载态 | 不用菊花转圈，用呼吸光点/水波 |
| 空状态 | 留白 + 一句温柔文案（见《00》文案调性） |
| 错误态 | 暮霞色提示，文案不责备用户 |
| 后台播放 | 全局播放器浮窗常驻，退出小程序可续播 |
| 沉浸页 | 呼吸练习等全屏沉浸页隐藏 Tab，仅留退出 |
| 表单 | 必须用真实 `<input>/<textarea>`，**禁止用 div 冒充输入框** |

## 八、结语

交互逻辑是骨架的"神经"。每一处按钮都应回到《00》的原点：**这一处，让人更安静了吗？** 不为交互而交互，不为功能而功能。

本文档覆盖 33 页全部按钮的规范定义；原型 HTML 的接线缺口见第四章，建议在转小程序时一并补齐，使"所有按钮都能互动"从规范变成现实。
