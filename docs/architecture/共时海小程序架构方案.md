## 五、管理后台现状

`backend/admin/index.html` 是完整单文件 SPA，8 面板 + 品牌色对齐：

| 面板 | 数据源 | 操作 |
|------|--------|------|
| 仪表盘 | API → /contents, /events, /signups | 统计卡片 + 最近报名 |
| 内容管理 | API → GET /contents, POST, PUT, DELETE | 搜索/类型筛选/增删改弹窗 |
| 疗愈师管理 | API → GET /healers, POST, PUT, DELETE | 增删改弹窗 |
| 活动管理 | API → GET /events, POST, PUT, DELETE | 搜索/状态筛选/增删改 |
| 订单管理 | API → GET /signups, DELETE | 状态筛选/删除 |
| 用户管理 | API → GET /users | 搜索/只读 |
| 共修圈 | API → GET /circles | 只读 |
| 基础配置 | 每日一语/危机热线/呼吸法/节气 | 4 子标签增删改 |

> API 不可用时自动降级到内置 mockData，页面不白屏。
